# 🧠 Proyecto – Grafo con Algoritmo de Prim
Este proyecto implementa un grafo no dirigido en **C# (Windows Forms)** y aplica el **algoritmo de Prim** para obtener su **Árbol de Expansión Mínima (MST)**.  
Permite agregar vértices, crear aristas con pesos y visualizar el resultado en la interfaz.

---

## 🛠️ Tecnologías utilizadas
- **C#**
- **.NET Framework**
- **Windows Forms**

---

## ▶️ Cómo ejecutar el proyecto
1. Descargar o clonar este repositorio.
2. Abrir el archivo `*.sln` en **Visual Studio**.
3. Compilar y ejecutar el proyecto.

---

## 📁 Estructura principal del proyecto
- `Program.cs` — Punto de entrada de la aplicación.
- `Form1.cs` — Interfaz gráfica y manejo de eventos.
- `Grafo.cs` — Lógica principal del grafo.
- `Vertices.cs` — Clase para modelar cada vértice.


---

## 📌 Funcionalidades
- Insertar vértices.
- Conectar vértices mediante aristas con peso.
- Visualización gráfica del grafo.
- Ejecución del algoritmo de Prim en el grafo creado.
- Obtención del árbol de expansión mínima.

---

## 🤖 Algoritmo de Prim (resumen)
1. Se elige un vértice inicial del grafo.
2. Se selecciona la **arista de menor peso** que conecte un vértice visitado con uno no visitado.
3. Se agrega el nuevo vértice al conjunto de visitados.
4. Se repite el proceso hasta conectar todos los vértices sin formar ciclos.
